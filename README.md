# ESOF-4559-DigitalImageProcessing
Driver distraction detection and image processing

Data set is collected from https://www.kaggle.com/competitions/state-farm-distracted-driver-detection/data
Download and extract to Matlab project folder

Run driver.m as the main program.
  Program will verify original files
  Split files into train and test set
  Perform image processing on files and store in new directory
  Train baseline and adjusted prediction model
  Validation model on training dataset
